All test versions of DataCite services require test account credentials (an Account ID and password). This is a separate set of credentials from DataCite production service credentials.

As with our production services, there are [different types of accounts](https://support.datacite.org/docs/datacite-account-types) in the test system. To test creating and managing DOIs, you will need a a test **Repository** account.

## Request a test account&#x20;

DataCite staff will create test accounts for Direct Members and Consortium Leads during onboarding.

- Direct Members have the authority and responsibility for creating test accounts for their Repositories.
- Consortium Leads are responsible for creating test accounts for their Consortium Organizations. If you are part of a Consortium, please contact your Consortium Lead for help with setting up a test account.

DataCite staff can also create test accounts for potential Members who have not yet joined. If you are considering membership and would like a test account, please contact DataCite support at [support@datacite.org.](mailto:support@datacite.org.)

## Set up your test account

After your test account has been created you will receive an automated email from the test instance of Fabrica containing a _Generate password_ link.


<Image src="https://files.readme.io/9ca7a8f-afc05a2-Email.PNG" alt="1150" align="center" caption="Password generation email from Fabrica Test" border={true} />


Clicking on _Generate a password_ takes you to the _Set Password_ page. You can set your own password or have one automatically suggested for you.


<Image src="https://files.readme.io/a03af13-5768f9b-SetPassword.PNG" alt="1284" align="center" caption="Password setting page in Fabrica Test" border={true} />


Clicking on _Submit_ will set the password and will take you to the _Sign in_ page. Click the _Sign in_ button in the upper right corner of your screen and enter your Account ID and password. You will find your Account ID in the same system email as the password link.

## Use your test account

The same test account credentials work for all DataCite services that have a test instance. These test services will have "test" in the URL. These test services are:

- Fabrica ([https://doi.test.datacite.org](https://doi.test.datacite.org))
- REST API ([https://api.test.datacite.org](https://api.test.datacite.org))
- MDS API ([https://mds.test.datacite.org](https://mds.test.datacite.org))
