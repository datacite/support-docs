Repository Search in DataCite Commons allows users to search for any repository profile that exists in DataCite and [re3data](https://www.re3data.org/). DataCite Members should make sure their DataCite Repository account is linked to the corresponding re3data record by including the re3data record in the Repository settings in DataCite Fabrica.

To do this, log in to Fabrica and navigate to the Repository settings tab. Type the name of the repository into the re3data record field and the look-up functionality will automatically find the corresponding re3data record.
