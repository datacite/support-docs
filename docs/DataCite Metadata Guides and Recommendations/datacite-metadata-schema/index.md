## The DataCite Metadata Schema

The DataCite Metadata Schema is a list of core metadata properties chosen for accurate and consistent identification of a resource for citation and retrieval purposes, with recommended use instructions in the documentation.

All DataCite Metadata Schema documentation is available on the schema website: <https://schema.datacite.org/>.

## DataCite Metadata Schema 4.7

The latest minor version of the DataCite Metadata Schema is Schema 4.7.

Documentation for the latest version is hosted on Read the Docs: <https://datacite-metadata-schema.readthedocs.io/en/4/>.

Documentation and examples can be accessed from the schema website: <https://schema.datacite.org/meta/kernel-4/>

## Metadata Schema Suggestions

We are interested in your suggestions to improve the DataCite Metadata Schema. Learn more about [how to contribute](https://schema.datacite.org/contribute.html).
