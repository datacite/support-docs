Metadata is an essential component of the persistent identifier (PID) infrastructure. DataCite DOIs are accompanied by a [metadata schema](http://schema.datacite.org/). There are 6 required properties, which are mandatory in order to register a [findable DOI](doc:doi-states). However, there are many more properties which enhance the possibilities for understanding, discovering and tracking research outputs. Researchers, repositories, institutions and funders can all benefit from investing in metadata.

The following series of infographics is designed to help increase awareness of the different metadata properties that can be used when registering a DataCite DOI and highlight the benefits of using these properties.
